GENEALIZ — ambiente visual sintético
Executar npm run dev:fixtures. Somente dados fictícios; nenhuma conta real é necessária. O resolver da configuração substitui o cliente Supabase, OAuth e funções externas apenas neste processo. Áudio/RPC/autenticação externa permanecem desativados. A revisão e as alterações da árvore fictícia podem sobreviver à recarga na mesma aba. O exercício público conserva alterações em memória enquanto está aberto. A configuração recusa build e não é importada pela configuração de produção. Não usar este ambiente como prova de persistência, RLS, e-mail ou processamento real.
